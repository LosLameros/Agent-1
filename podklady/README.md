# Podklady pro čtvrtletní zprávy

Pro každé čtvrtletí založ složku `RRRR-Qn` (např. `2026-Q3/`) a nahraj do ní dva hotové grafy jako PNG, JPG nebo PDF:

- „Zhodnocení vybraných tříd aktiv: nQ RRRR"
- „Portfolia na míru v roce RRRR" (nebo „Portfolia od Portu v roce RRRR")

Agent `ctvrtletni-zpravy` je odsud načte. Přílohy z chatu sám nevidí.
