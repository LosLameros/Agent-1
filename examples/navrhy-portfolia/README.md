# Vzory e-mailů s návrhem portfolia

Sem patří dřívější e-maily poradce klientům s návrhem, kolik a do čeho zainvestovat. Subagent `navrh-portfolia` z nich přebírá styl.

- Jeden e-mail = jeden soubor `RRRR-MM-DD-kratky-popis.md` (např. `2026-10-15-8-milionu-realitni-fond-a-profil-10.md`).
- Pokud to jde, dej nad e-mail i krátké zadání: co klient měl, o čem jste se bavili, kolik a do čeho. Agent pak vidí, jak se zadání promítlo do textu.
- Vzory jsou v gitu, proto je **anonymizuj**: bez jmen, e-mailů, telefonů a čísel smluv (jméno nahraď `[klient]`).
