# Archiv názorových článků

Vzorové názorové články hlavního ekonoma a analytiků Portu. Slouží subagentovi `nazorove-clanky` (`.claude/agents/nazorove-clanky.md`) jako závazný vzor pro délku, stavbu, tón a způsob, jakým autor dojde k pointě.

Články jsou uložené **doslova**, ve verzi, jak vyšly (nebo jak je autor odeslal novinářům). Název souboru: `RRRR-MM-DD-tema.md`, v hlavičce souboru médium a datum vydání, pokud je známé.

| Soubor | Autor | Médium / datum vydání | Téma a teze |
|---|---|---|---|
| _zatím prázdné, vzory doplní uživatel_ | | | |

Nové hotové články ukládá agent do `vystupy/nazorove-clanky/`. Když článek vyjde, uloží jeho finální verzi sem a doplní tabulku.
