# Písma pro nastroje/faktura.py

Roboto (Regular, Medium, Bold) z Google Fonts. Je to stejné písmo, jaké používají faktury z FakturaOnline.cz.
Licence: SIL Open Font License 1.1 (https://openfontlicense.org), autor Google / Christian Robertson.
Písmo je bez hintingu a obsahuje jen latinku (U+0020–017F, €, pomlčky a uvozovky). PDF je díky tomu asi o čtvrtinu menší a vypadá stejně. Soubory jsou v repozitáři, aby faktura vypadala stejně na každém počítači.
